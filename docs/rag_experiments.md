## 实验 2：Chunk Size 对比

模拟不同文档切片大小对关键词检索命中率的影响。

| 切片策略 | 平均命中数 (max=3) |
|---------|-------------------|
| chunk=200 | 1.20 |
| chunk=500 | 1.20 |
| chunk=1000 | 1.20 |
| 整篇不分块 | 1.20 |

### 结论

在当前小规模文档集下，分块策略对命中率无显著影响（均维持在 1.20/3），原因是文档本身较短（60-100 字），分块后信息分布变化不大。建议生产环境中根据实际文档长度动态选择 500 字左右的分块，同时保留整篇索引作为兜底。

## 整体结论与建议

1. **RRF 融合**整体优于单一检索策略，推荐作为默认检索方式。
2. **Chunk Size** 在当前小语料下无显著差异，建议生产环境按文档长度动态选择 500 字左右分块。
3. **Reranker 重排序**在基线已达上限时无提升，但可在噪声场景下有效改善排序质量。
4. 当前种子数据量较小（8 篇），上述结论在大规模知识库中可能有所变化。
