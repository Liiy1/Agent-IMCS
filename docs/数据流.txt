
  一次问诊请求的数据流转（以"头痛三天"为例）：

  ① 请求进入
     用户 POST → {session_id, message: "头痛三天", user_token}

  ② 加载状态
     Redis 查询 → 命中返回 / 未命中查 MySQL → 回写 Redis

  ③ 症状提取 (collect)
     请求 LLM：从"头痛三天"中提取症状和病史
     LLM 返回：{"symptoms": ["头痛"], "history": []}

  ④ 条件判断 A
     collected_symptoms = ["头痛"] → 1个 < 3个 → 追问
     ✓ 返回："您已提到：头痛。请再详细描述一下..."

  ⑤ 用户补充 → "还有发烧、恶心"
     再次进入流程...
     collected_symptoms = ["头痛", "发烧", "恶心"] → 3个 ≥ 3个 → 继续

  ⑥ 知识检索 (retrieve)
     ChromaDB 向量检索 → 返回 Top-10
     关键词重排序 → RRF 融合 → 输出 Top-5 医学文档
     返回：发热定义、头痛分类等文档内容

  ⑦ 分析诊断 (analyze)
     请求 LLM：症状 + 病史 + 医学知识
     LLM 返回：诊断分析 + urgency: medium + 科室: 神经内科/感染科

  ⑧ 反思评审 (reflect — 新增)
     请求 LLM 评审诊断质量（一致性/完整性/准确性）
     LLM 返回：评分 + 反馈 + 是否通过
     ├─ 通过 → 继续生成报告
     ├─ 不通过 & 轮次未用尽 → 回 ⑦ 精炼（带上反馈）
     └─ 不通过 & 轮次用尽 → 强制继续 + 报告追加人工复核声明

  ⑨ 报告生成 (generate_report)
     请求 LLM：基于诊断分析生成结构化 Markdown 报告
     LLM 返回：完整报告（主诉、诊断分析、建议检查等）
     （若轮次用尽且质量不达标，报告开头加 ⚠️ 建议人工复核）

  ⑩ 持久化
     乐观锁保存状态 → MySQL upsert + Redis 更新
     保存消息记录 → MySQL messages 表

  ⑪ 返回
     {response: 报告, urgency_level, is_complete, session_id}


  精炼循环示例（假设第一轮评分 2/5，未通过）

                   ┌──────────────────────────────────────┐
                   │  ⑦ analyze（初版分析）                │
                   │     round=0                          │
                   └──────────────┬───────────────────────┘
                                  │
                                  ▼
                   ┌──────────────────────────────────────┐
                   │  ⑧ reflect（评分 2/5，不达标）        │
                   │     feedback: "缺少对发热时间的描述"   │
                   └──────────────┬───────────────────────┘
                                  │ 不达标 & round(0) < max_rounds(2)
                                  ▼
                   ┌──────────────────────────────────────┐
                   │  ⑦ analyze（精炼 — 带上反馈）          │
                   │     输入初版分析 + reflect feedback   │
                   │     round=1                          │
                   └──────────────┬───────────────────────┘
                                  │
                                  ▼
                   ┌──────────────────────────────────────┐
                   │  ⑧ reflect（评分 4/5，达标）          │
                   └──────────────┬───────────────────────┘
                                  │ 通过
                                  ▼
                   ┌──────────────────────────────────────┐
                   │  ⑨ generate_report                   │
                   └──────────────────────────────────────┘
